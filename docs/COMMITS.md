# 提交学习索引

每完成一个阶段，在这里追加一行。目的是让提交历史本身成为一份可以回顾的学习材料。

| 提交标题 | 阶段 | 涉及概念 | 学习要点 |
| --- | --- | --- | --- |
| 初始化: 建立仓库基线与项目约定 | 阶段 0 | Git 仓库初始化、`.gitignore`、公开/私有内容分离 | 静态博客可以把「代码公开、内容私有」做在同一套目录里：用 `.gitignore` 排除内容路径，代码照常协作 |
| 新增: 建立主题骨架与设计令牌 | 阶段 1 | 主题目录结构、`layout.ejs` 包装机制、CSS 变量、界面文案 i18n | Hexo 会用主题的 `layout.ejs` 自动包住 `index.ejs`、`post.ejs` 等页面视图（路由 locals 默认 `layout = 'layout'`），所以页面模板只写内容区 |

## 使用说明

- 「提交标题」直接复制 commit 的第一行，可用 `git log --oneline` 对照。
- 「涉及概念」写这一阶段用到的 Hexo、Git 或 CSS 机制。
- 「学习要点」写自己最想记住的结论，一条即可，不求全。
