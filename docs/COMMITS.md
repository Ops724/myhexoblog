# 提交学习索引

每完成一个阶段，在这里追加一行。目的是让提交历史本身成为一份可以回顾的学习材料。

| 提交标题 | 阶段 | 涉及概念 | 学习要点 |
| --- | --- | --- | --- |
| 初始化: 建立仓库基线与项目约定 | 阶段 0 | Git 仓库初始化、`.gitignore`、公开/私有内容分离 | 静态博客可以把「代码公开、内容私有」做在同一套目录里：用 `.gitignore` 排除内容路径，代码照常协作 |
| 新增: 建立主题骨架与设计令牌 | 阶段 1 | 主题目录结构、`layout.ejs` 包装机制、CSS 变量、界面文案 i18n | Hexo 会用主题的 `layout.ejs` 自动包住 `index.ejs`、`post.ejs` 等页面视图（路由 locals 默认 `layout = 'layout'`），所以页面模板只写内容区 |
| 新增: 搭建双语内容模型与语言路由基础 | 阶段 2 | 内容模型 front-matter、语言归一化过滤器、站点级生成器覆盖、URL 前缀语言识别 | 双语不是 Hexo 的内置能力：Hexo 只按 URL 前缀识别「界面语言」，内容归属必须自己用 `lang` 字段加生成器过滤来实现 |
| 新增: 实现首页与生活频道分页 | 阶段 3 | 生成器覆盖、分页路由约定、EJS partial 复用、内容摘要 helper | 分页不一定要依赖 hexo-pagination：把文章切片后按「第 1 页是频道地址、第 N 页是 page/N」生成路由即可 |
| 新增: 实现文章详情页与内容排版 | 阶段 4 | Prism 服务端高亮、文章资产目录、相邻文章查找、译文入口 | 文章页拿到的 page.path 是路由路径，而文章集合里的 path 是 permalink，跨来源比较路径时要先归一化 |

## 使用说明

- 「提交标题」直接复制 commit 的第一行，可用 `git log --oneline` 对照。
- 「涉及概念」写这一阶段用到的 Hexo、Git 或 CSS 机制。
- 「学习要点」写自己最想记住的结论，一条即可，不求全。
